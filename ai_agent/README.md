🛡️ Chrome Extension Security AI Agent

An AI-powered cybersecurity assistant built with Google Agent Development Kit (ADK) and the Google Gemini API, designed to analyze the security posture of installed Chrome browser extensions.The agent connects to a custom endpoint-based extension scanner, consumes the security data generated by the scanner, and uses Gemini to analyze, explain, summarize, and report on the results.

Project Status: 🚧 Active Development

🚀 Overview

Browser extensions can request powerful permissions and interact with sensitive browser resources. This can make it difficult for users to determine whether an extension is trustworthy. This project provides a conversational cybersecurity assistant that allows users to investigate Chrome extension security using natural language.

The system separates security data collection from AI-powered analysis:

🔍 Custom Endpoint Scanner — Performs extension scanning and generates structured security data.
🤖 Google ADK — Provides the agent framework and tool orchestration.
🧠 Google Gemini — Provides reasoning and natural-language analysis.
📊 Historical Analysis — Allows the agent to investigate changes between scans.
📝 Security Reports — Generates human-readable Markdown security reports.

The AI agent is an optional analysis layer over the endpoint scanner. It does not replace the scanner and does not currently integrate directly with Wazuh.

✨ Features
🔍 Run Extension Scans

The agent can request a security scan of installed Chrome extensions through the custom scanner endpoint.

The scanner can provide information such as:

Extension names and IDs
Extension versions
Requested permissions
Host permissions
Security findings
Risk information
Scan results
Historical scan data

The exact information available to the agent depends on the version and configuration of the endpoint scanner.

📊 Retrieve Scan Results

The agent can retrieve and summarize scanner results.

It can help identify:

Total extensions scanned
Extensions requiring attention
Security findings
Risk information
Overall security posture

Example:

User:
What did my latest scan find?


The agent retrieves the latest scanner results and provides a human-readable security summary.

⚠️ Analyze Extension Risk

The agent can explain the security factors associated with an extension.

Depending on the data available from the scanner, analysis can consider:

Permissions
Host permissions
Security findings
Suspicious behavior
Risk scores
Threat intelligence

For example, instead of simply reporting:

Risk Score: 82/100


the agent can explain the security factors contributing to the result.

Note: The endpoint scanner has been extended with additional risk-scoring and threat-intelligence capabilities after the initial AI-agent implementation. Full AI-agent interpretation of these newer capabilities is still under development.

🔐 Permission Analysis

The agent can explain potentially sensitive Chrome permissions and their security implications.

For example:

Extension: Example Extension

Permissions:
- tabs
- storage
- cookies

Host Permissions:
- <all_urls>


The agent can explain that broad website access and permissions such as tabs or cookies may allow an extension to interact with sensitive browser resources.

📈 Historical Security Analysis

The agent can compare previous scan results and investigate changes over time.

This can include:

Permission changes
Host permission changes
Version changes
Risk score changes
New findings
Resolved findings

Example:

User:
Has this extension become more risky recently?


The agent can compare historical scanner results and explain the changes.

📝 Generate Security Reports

The agent can generate comprehensive Markdown security reports based on the available scanner data.

A report may contain:

Chrome Extension Security Report

🔌 Custom Endpoint Scanner

The AI agent is designed to work with a custom security scanner exposed through an API endpoint. The scanner performs the underlying security analysis and exposes structured results that the AI agent can consume.

A typical architecture is:

ADK Agent
    │
    │ HTTP / REST
    ▼
Scanner Endpoint
    │
    ▼
Chrome Extension Scanner
    │
    ├── Extension Metadata
    ├── Permissions
    ├── Host Permissions
    ├── Code Analysis
    ├── Risk Scoring
    ├── Threat Intelligence
    └── Historical Data


The exact endpoint structure depends on the implementation of the custom scanner.

Scanner Dependency

The AI agent depends on the endpoint scanner for its security data. If the scanner endpoint is unavailable, the agent cannot perform live scans or retrieve current scanner results. The AI agent does not independently perform the underlying Chrome extension security scanning.

⚠️ Security Considerations

This project is designed for defensive security analysis.
AI-generated analysis should be treated as an interpretation of available scanner data rather than an absolute security verdict.
A high risk score does not necessarily prove that an extension is malicious, and a low risk score does not guarantee that an extension is completely safe.
Critical findings should be verified using appropriate security tools and trusted sources.
API credentials and other secrets must not be committed to the repository.


⚠️ Limitations
Analysis quality depends on the data returned by the endpoint scanner.
The current AI-agent implementation was developed against an earlier version of the endpoint scanner.
The scanner has since gained additional security-analysis and threat-intelligence capabilities that have not yet been fully integrated into the agent's reasoning.
Gemini may occasionally produce incorrect or incomplete interpretations.
Threat-intelligence analysis depends on the services integrated with the scanner.
Risk scores are indicators rather than definitive proof of malicious behavior.
Real-time scanning requires the custom scanner endpoint to be available.
The agent cannot guarantee that an extension is completely safe.

🚧 Development Status

The AI Security Agent is currently under active development.

The core components of the agent—including Google ADK integration, Gemini integration, custom scanner connectivity, security analysis, historical analysis, and Markdown report generation—have been implemented.

The initial implementation was developed against an earlier version of the endpoint scanner. The scanner has since been extended with additional capabilities, including enhanced risk scoring and threat-intelligence integrations.The agent has not yet been fully updated to interpret all of these newer scanner capabilities. Future development will focus on improving the agent's ability to consume and reason over the latest scanner output, including newer risk-scoring and threat-intelligence data.The AI agent therefore represents an ongoing extension of the endpoint-scanner platform, rather than a replacement for the existing security detection or Wazuh infrastructure.

📜 Disclaimer

This project is intended for security research, defensive security, and personal/authorized use.

Only scan browser extensions, systems, and endpoints that you own or have explicit permission to analyze.

AI-generated security analysis should not be considered a definitive security verdict. Critical findings should be independently verified.
